# Civic Pulse

## Introduction

Civic Pulse is an AI-powered platform that helps citizens report civic issues and enables authorities to identify, analyze, and prioritize problems using dashboards and heatmaps.

---

## Features

* Complaint Submission
* AI-Based Classification
* Duplicate Complaint Detection
* Interactive Heatmap
* Analytics Dashboard
* Priority Ranking

---

## Installation

### Clone Repository

git clone <repository-url>

### Install Dependencies

pip install -r requirements.txt

### Run Application

streamlit run app.py

---

## Using the Application

### Submit Complaint

1. Open the application.
2. Select "Submit Complaint".
3. Enter issue details.
4. Select category.
5. Enter location.
6. Click Submit.

### Dashboard

View:

* Total Complaints
* Category Distribution
* Hotspot Areas
* Trends and Statistics

### Heatmap

Navigate to Heatmap section to view issue concentration across locations.
