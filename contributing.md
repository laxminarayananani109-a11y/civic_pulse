# Contributing Guidelines

Thank you for contributing to Civic Pulse.

## Getting Started

1. Fork or clone the repository.
2. Pull the latest changes from the main branch.
3. Create a new feature branch.
4. Implement your assigned task.
5. Test your changes.
6. Commit and push your code.
7. Create a Merge Request.

## Branch Naming Convention

* feature/complaint-form
* feature/ai-classification
* feature/heatmap
* feature/dashboard
* bugfix/issue-name

## Commit Message Guidelines

Use clear commit messages:

* Added complaint submission form
* Implemented AI classification
* Added heatmap visualization
* Updated dashboard analytics
* Fixed database connection issue

## Coding Standards

* Follow Python best practices.
* Use meaningful variable names.
* Keep functions modular.
* Add comments where necessary.
* Maintain consistent formatting.

## Team Responsibilities

### Member 1 – Project Lead & Integration

Responsible for integrating modules and ensuring smooth project execution.

### Member 2 – Data Engineer

Responsible for data processing and database management.

### Member 3 – AI Engineer

Responsible for machine learning and classification models.

### Member 4 – Frontend Developer

Responsible for UI development and user experience.

### Member 5 – Visualization & Documentation

Responsible for charts, maps, reports, and documentation.

## Pull Request Process

1. Ensure code is tested.
2. Resolve merge conflicts.
3. Request review from team members.
4. Merge only after approval.

## Communication

Maintain regular updates through team meetings and GitLab discussions to ensure smooth collaboration.
