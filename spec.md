# Civic Pulse Specification

## Goal

Provide a platform for citizens to report civic issues and track their resolution.

## Features

* User registration and login
* Civic issue reporting
* Image uploads
* Issue status tracking
* Upvoting issues
* Notifications
* Admin dashboard
* Analytics dashboard

## User Roles

* Citizen
* Administrator

## Success Criteria

* Users can report issues successfully.
* Administrators can manage and resolve issues.
* Users can track progress in real time.
